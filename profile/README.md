# retrokidworks

Indie apps, games and music. [retrokidworks.com](https://retrokidworks.com)

## Open source

**[Allnighter](https://allnighter.retrokidworks.com)** — keep your Mac awake with the screen off.
A menu bar app that turns the display backlight all the way down while your Mac keeps working, and can run with the lid closed.

```sh
brew install --cask retrokidworks/tap/allnighter
```
